🧛 吸血鬼 Widget — embed.js 測試

通過 data- 属性配置，所有參數傳遞給 widget.html iframe

用法 1：默認配置（吸血鬼模型）

最簡單的調用方式，只需要在頁面底部加入一行 script標籤：

<script src="https://vampire.kitahim.uk/static/embed/embed.js"
  data-model="https://vampire.kitahim.uk/static/live2d/vampire/%E5%90%B0%E8%A1%80%E9%AC%BC.model3.json"
  data-knowledge="https://vampire.kitahim.uk/static/embed/knowledge.js"
  data-api="/api/tts">
</script>

用法 2：自定義 API endpoint

如果你的後端在不同地址，可以通過 data-api 屬性指定：

<script src="https://vampire.kitahim.uk/static/embed/embed.js"
  data-api="https://your-backend.com/api/tts"
  data-model="https://vampire.kitahim.uk/static/live2d/vampire/%E5%90%B0%E8%A1%80%E9%AC%BC.model3.json">
</script>

用法 3：控制 widget 開/關

可以通過 window.AvatarWidget 程序化控制：

// 關閉 widget
window.AvatarWidget && window.AvatarWidget.setOpen(false);

// 打開 widget
window.AvatarWidget && window.AvatarWidget.setOpen(true);

// 監聽狀態變化
window.addEventListener('message', (e) => {
  if (e.data.ns === 'avatar-widget-host' && e.data.type === 'status') {
    console.log('Widget 狀態:', e.data);
  }
});

iframe + postMessage 通訊

父頁面可以通過 postMessage 向 widget 發送命令：

const iframe = document.querySelector('#avatar-widget-root iframe');
iframe.contentWindow.postMessage({
  ns: 'avatar-widget-host',
  type: 'react',
  text: 'Hello widget!',
  context: { source: 'test' }
}, '*');
